# TataDana - Solusi Praktis Kelola Keuangan
Kelola keuangan Anda dengan mudah dan fleksibel, kapan saja dan di mana saja, baik melalui aplikasi maupun bot Telegram.
Fitur Utama: Manajemen anggaran, pencatatan pemasukan dan pengeluaran, laoran keuangan bulanan, integrasi bot Telegram untuk catat cepat.
Cara Penggunaan: Daftarkan akun, mulai mencatat data transaksi secara rtin, dan manfaatkan bot Telegram untuk pencatatan instan.
